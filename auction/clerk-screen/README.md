# The Clerk Screen

The clerk screen is the page of the live app from which the clerk runs the auction: it sets the auction status and session, opens and closes each lot, and enters the bids from the room.

## Opening the clerk screen

1. In the backoffice, open the sale (**Sales**, then click the sale).
2. On the **Sale** tab, find the **Sale Links** block and click **Clerk page**. The clerk screen opens in a new browser tab.

![The Sale Links block on the sale page, with the Clerk page link](../../assets/screenshots/sale-links-clerk-page.png)

The links to the live app appear only when the sale is synced to the Bid Server. The same block also opens the **Sale live app** (what bidders see), the **Auctioneer page** and the **Room page**.

## The parts of the screen

![The clerk screen with a lot open for bidding](../../assets/screenshots/auction-clerk-active.png)

| Part | What it is for |
| :--- | :--- |
| **Status** \(top left\) | The auction status, for example *Live auction open*. Pick a status and click the arrow to apply it. See [How to Set the Auction Status](how-to-set-the-action-status.md). |
| **Session** \(top centre\) | The session being sold. See [How to Set the Auction Session](how-to-set-the-action-session-and-status.md). |
| **Auto-clerk** \(top right\) | Switches automatic clerking on or off. |
| **Lot card** \(left\) | The current lot: number, state, description, image, and its start, opening and minimum prices. **Lot progress** shows how far the session has advanced. |
| **Navigation** \(bottom left\) | **Prev**, **Next** and **Jump to lot** move to another lot. See [How to Select the Bidding Item](how-to-select-the-bidding-item.md). |
| **Bidding panel** \(centre\) | The opening or current price, **Place bid**, **Enter amount**, **Set to floor** and **Step**. See [How to Place a Bid from the Floor](how-to-place-a-bid-from-the-room.md). |
| **Stand by / Open / Going / Gone** | The state of the current lot. See [Auction Flow](../auction-flow.md). |
| **Bids**, **Book bids**, **Closed** | The bids placed on the current lot, the book bids waiting for it, and the lots already closed. |
| **Messages** \(right\) | The feed of what happened in the auction, and a field to send a public or private message to the bidders. |
| **Connected users** | The bidders currently connected to the live auction. |
