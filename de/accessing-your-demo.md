# Zugang zu Ihrer Demo

Wählen Sie eine Auktion:  
![Bild](../assets/screenshots/sale-context-autocomplete.png)

Die zutreffenden „Sale Links“ erscheinen im Block Sale Links auf der Auktionsseite.  
![Bild](../assets/screenshots/sale-links.png)

### Auktionsseite \(Kunden\)

Die Webseite, die die Online-Nutzer während der Live-Auktion sehen. Hinweis: ALLE Nutzer der Live-App müssen sich zuerst über diese Auktionsseite anmelden.

### Clerk-Seite \(Mitarbeiter\)

Die Webseite für die Person, die die Gebote erfasst und die Anweisungen des Auktionators umsetzt, etwa das Gebot auf Saalgebot zu setzen oder den nächsten Bietschritt zu ändern.

### Auktionatorseite \(Mitarbeiter\)

Die Webseite für die Person, die den Hammer hält und die Auktion im Saal leitet. Diese minimalistische Seite zeigt nur, was der Auktionator zur Durchführung der Auktion benötigt.

### Saalseite

Diese Seite dient dazu, die Live-Auktion auf dem Monitor im Auktionssaal anzuzeigen.

Um das System gleichzeitig aus verschiedenen Rollen \(Mitarbeiter oder Kunde\) zu sehen, verwenden Sie bitte für jede Rolle ein eigenes Fenster \(eines in Chrome und das andere in Chrome Inkognito\). Zum Einstieg erhalten Sie eine Tabelle wie die folgende, in der Ihre jeweiligen Zugangsdaten eingetragen sind.

| MITARBEITER \(Chrome-Browser\) | Link zur Seite | Benutzername des Mitarbeiters | Passwort |
| :--- | :--- | :--- | :--- |
| Backoffice |  |  |  |
| Live-App: Clerk-Seite | Sale-Link im Backoffice |  |  |
| Live-App: Auktionatorseite | Sale-Link im Backoffice |  |  |

| KUNDE \(Chrome Inkognito\*\) | Link zur Seite | Benutzername des Kunden | Passwort |
| :--- | :--- | :--- | :--- |
| Website \(eKatalog\) |  |  |  |
| Live-App: Auktionsseite | Sale-Link im Backoffice |  |  |

\*Für Chrome im [Inkognito-Modus](https://de.wikipedia.org/wiki/Privater_Modus) gehen Sie im Browsermenü auf Datei → Neues Inkognito-Fenster.

**Bitte beachten Sie:**  
Ganz oben gibt es einen Auktionskontext-Eintrag. Wählen Sie unbedingt eine Auktion aus, damit die Seite „Gebote“ und die „Gebotsinformationen“ verfügbar sind.  
![Bild](../assets/screenshots/sale-context-selected.png)

Bitte beachten Sie, dass das Stecker-Symbol oben rechts auf Ihrem Bildschirm grün sein sollte. Wenn nicht, klicken Sie darauf und anschließend auf **Neuladen**.  
![Bild](../assets/screenshots/bid-server-reconnect.png)
