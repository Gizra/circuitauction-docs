# Gebote

Das Modul Gebote ist die zentrale Anlaufstelle zur Verwaltung aller Gebotsaktivitäten einer Auktion. Es umfasst das Eingeben von Geboten, die Prüfung des Gebotsstatus, die Verwaltung der Gebote einzelner Lose und die Anzeige der Gebotsinformationen von Kunden.

## Voraussetzungen

Um Gebote anzuzeigen, müssen Sie einen [Auktionskontext](../sale/sale-context.md) ausgewählt haben und mit dem Gebotsserver verbunden sein (erkennbar am grünen Symbol oben auf der Seite).

![Anzeige der Verbindung zum Gebotsserver](../../assets/screenshots/bid-server-icon-green.png)
