# Empfohlener Ablauf

1. Legen Sie einen Kunden \(Einlieferer\) an. Siehe [So legen Sie einen Kunden an](/de/client/how-to-create-a-client.md).   
2. Legen Sie eine Auktion an. Siehe [So erstellen Sie eine Auktion](/de/sale/how-to-create-a-sale.md).
3. Legen Sie auf der Seite des Einlieferers \(Kunden\) eine Einlieferung an. Siehe [So legen Sie eine Einlieferung an](/de/consignment/how-to-create-a-consignment.md).
4. Erstellen Sie Lose aus der Einlieferung. Siehe [So fügen Sie einer Einlieferung ein Los hinzu](/de/consignment/how-to-add-an-item-to-consignment.md).  
5. Weisen Sie Lose einer Auktion zu. Das geschieht im Lose-Dashboard \([Sammelzuweisung](/de/sale/how-to-assign-bulk-items-to-a-sale.md)\) oder auf der Losseite \([einzeln](/de/items/how-to-create-an-item.md)\).
6. Weisen Sie den Losen Losnummern zu. Siehe [So weisen Sie Losnummern zu](/de/sale/how-to-assign-lot-numbers.md).
7. Veröffentlichen Sie die Auktion auf der Website.
8. Führen Sie die Auktion durch
9. Rechnungen an Käufer und Einlieferer
10. Export in die Buchhaltung
