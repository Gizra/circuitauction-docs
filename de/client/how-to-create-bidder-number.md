# So legen Sie eine Bieternummer an

## Bieternummern registrieren

1. Stellen Sie sicher, dass Sie sich im richtigen [Auktionskontext](../sale/sale-context.md) befinden.
2. Öffnen Sie die Kundenseite \(siehe [So finden Sie einen vorhandenen Kunden](how-to-find-an-existing-client.md)\)
3. Wechseln Sie zum Tab `Gebotsinformationen`.
4. Gehen Sie zum Bereich `Bieternummer` \(`Register New Bidder Numbers`\).
5. Wählen Sie den Bietertyp \(Floor, Floor by agent, Webseite, Mail, Telefon oder External\).
6. Geben Sie die Bieternummer ein oder lassen Sie das Feld leer, damit das System die Nummer vergibt. Optional können Sie auch einen Alias eingeben.
7. Klicken Sie auf **Register Bidder**.

![](/assets/screenshots/bidder-numbers-create.png)

1. Jede Bieternummer wird in einem eigenen Block angezeigt:

![](/assets/screenshots/bidder-numbers-blocks.png)

1. Um zu begrenzen, wie viel der Bieter gewinnen kann, wählen Sie im Feld **Credit Limit** den Wert `Regular`, geben Sie den Betrag ein und klicken Sie auf die Schaltfläche „Speichern“ \(✓\).

![](/assets/screenshots/bidder-live-credit.png)

1. Um zu begrenzen, wie viel der Bieter bieten kann, wählen Sie im Feld **Bidder Limit** den Wert `Regular`, geben Sie den Betrag ein und klicken Sie auf die Schaltfläche „Speichern“ \(✓\). Beachten Sie, dass der Bieter sein persönliches Limit auch über seine Seite „My Account“ ändern kann.

![](/assets/screenshots/bidder-max-bid.png)

Beachten Sie, dass Sie mehrere Floor-Bieternummern registrieren können, aber nur eine Bieternummer für Webseite oder Telefon.

## Rückrufanfragen anlegen

1. Gehen Sie zum Bereich `Add New Call Request`.
2. Geben Sie den Bereich der **Lose** ein. Trennen Sie Losnummern mit einem Komma \(,\) und verwenden Sie einen Bindestrich \(-\) für Bereiche \(z. B. 101,200,300-310\).

![](/assets/screenshots/call-requests.png)

1. Geben Sie bei Bedarf eine Notiz ein und klicken Sie auf **Add Request**.
2. Eine Telefonbieternummer wird angelegt und der [Liste der Telefonbieterkarten](how-to-download-phone-bidder-cards-list.md) hinzugefügt.

![](/assets/screenshots/call-requests-saved.png)
