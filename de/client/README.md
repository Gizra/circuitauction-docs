# Kunden

Kunden sind alle Personen, mit denen Sie eine Geschäftsbeziehung haben: ein Einlieferer/Verkäufer oder ein Käufer/Bieter.

Im Kunden-Dashboard finden Sie eine Übersicht aller Kunden.

![](../../assets/screenshots/clients-dashboard.png)

Die farbigen Felder oben **\[1\]** zeigen die Gesamtzahl der Kunden und die Anzahl der Kunden je Status. Die Tabelle **\[2\]** zeigt die Kundenliste, die Sie nach jeder Spalte [filtern](/de/client/how-to-find-an-existing-client.md) können.

## Status

**Neu** - ein neuer Kunde, der sich im System registriert hat oder von einem Administrator angelegt wurde.  
**ausstehend** - ein Kunde, der auf die Freigabe zum Bieten oder Verkaufen wartet.  
**genehmigt** - ein freigegebener Kunde, der Lose verkaufen oder bei einer Auktion Gebote abgeben kann.  
**nicht genehmigt** - ein Kunde, der nicht für die Teilnahme an der Auktion freigegeben wurde.  
**Inaktiv** - ein Kunde, der deaktiviert wurde.

## Recht zum Bieten je Status

![client\_status\_ place\_bid \_rights\_-\_google\_docs](https://user-images.githubusercontent.com/20393485/46657024-0601c380-cbb8-11e8-881a-ed12de628706.jpg)  
**Mail** - der aktuelle Preis, der sich mit den abgegebenen Geboten ändert, wird dem Bieter angezeigt.  
**Obscure mail** - der Kunde sieht den aktuellen Preis nicht, sondern nur den Startpreis.
