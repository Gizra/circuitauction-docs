# So laden Sie die Liste der Telefonbieterkarten herunter

1. Stellen Sie sicher, dass Sie sich im richtigen [Auktionskontext](../sale/sale-context.md) befinden. 
2. Gehen Sie im Seitenmenü zu **Telefonbieterkarten**.

   Hier finden Sie eine Liste aller Telefonbieter der ausgewählten Auktion.

![](/assets/screenshots/phone-bidder-cards.png)

1. Klicken Sie in jeder Zeile auf **PDF**, um die Karte als PDF-Datei anzuzeigen. Sie können sie speichern oder über die Druckfunktion Ihres Browsers drucken.

![](/assets/screenshots/phone-bidder-cards-download.png)

1. Um die Karten für eine ganze Session herunterzuladen, klicken Sie auf **Download session phone bidders card** und wählen Sie die gewünschte Session aus.

![](/assets/screenshots/phone-bidder-cards-session.png)

1. Klicken Sie auf **Klicken zum herunterladen**

![](https://user-images.githubusercontent.com/20393485/46949148-136fef80-d089-11e8-97aa-e96f5c513c2a.jpg)

1. Die Kartenliste wird als PDF-Datei in einem neuen Browser-Tab geöffnet. Sie können sie speichern oder über die Druckfunktion Ihres Browsers drucken \(dieser Screenshot zeigt Chrome\).

![](https://user-images.githubusercontent.com/20393485/46949309-a3ae3480-d089-11e8-9da3-113993edfbc2.jpg)
