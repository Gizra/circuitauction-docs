# Workflow „Under Extension“

### So setzen Sie ein Los auf „Under Extension“

#### 1. Über die Gebotsseite im Backoffice

&#x20;Setzen Sie das UE-Flag über die Backoffice-App.\
![](/assets/screenshots/bids-ue-flag.png)

#### 2. Über die Live-App

Auf der Auktionator-Seite ist dies neben dem schriftlichen Gebot sichtbar.![](</.gitbook/assets/image (34).png>)

#### 3. Über die Losseite im Backoffice

Eine weitere Möglichkeit ist, das UE-Flag auf der Losseite zu setzen. Dies wird verwendet, um vor Auktionsbeginn Prüfungsaufgaben zu versenden.

![](/assets/screenshots/item-under-extension-top.png)

Hinweis: Mit UE markierte Gebote lösen den Workflow aus, wenn das Los mit diesem Gebot verkauft wird.

### &#x20;Workflow-Schritte

1. &#x20;Für den Philatelisten wird eine Aufgabe angelegt. ![](/assets/screenshots/task-under-extension.png)
2. Das Los erscheint auf der Einlieferungsabrechnung (CS) als UE und wird nicht in den Gesamtbetrag einbezogen.  ![](</.gitbook/assets/image (36).png>)
3. Die Losseite zeigt den UE-Status an: ![](/assets/screenshots/item-under-extension.png)
4. Hinweis: Wenn der UE-Status geändert wird, nachdem die CS geschlossen wurde, wird nur dann eine neue CS ausgelöst, wenn die Zahlung bei der ersten Zahlung ausgelassen wurde.
5. Sie können alle Anfragen im Tab „Order“ im Tab „Expert Orders“ verfolgen

![](</.gitbook/assets/image (22).png>)\
