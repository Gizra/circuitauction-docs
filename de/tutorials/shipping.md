# Versand

Sieben kurze Videos von je ein bis anderthalb Minuten zum Versand einer Rechnung, von Anfang bis Ende. Die schriftliche Anleitung finden Sie im Bereich [Versand](/de/shipping/README.md).

## 1. Sendung erstellen

Öffnen Sie in der Rechnung den Reiter **Versand / Verpackung**, klicken Sie auf **Neu hinzufügen**, wählen Sie die Adresse, klicken Sie auf **Kosten und Versanddienstleister abrufen**, wählen Sie einen Tarif und speichern Sie. Der berechnete Gesamtbetrag enthält Versicherung und Bearbeitungsgebühr.

## 2. Versandetiketten

Kaufen Sie das Etikett mit **Versandetikett erstellen**, laden Sie es als PDF oder ZPL herunter, sehen Sie, was ein Etikett sperrt, und stornieren Sie es mit **Cancel label**.

Mehr dazu unter [Etiketten und Sendungsverfolgung](/de/shipping/labels-and-tracking.md).

## 3. Verpacken

Setzen Sie die Sendung auf *To pack*, markieren Sie jedes Los als verpackt, machen Sie es mit **Mark as Unpacked** rückgängig, verteilen Sie die Lose auf mehrere Kartons und verpacken Sie per Scan.
