# Aktivitäten

Aktivitäten ist das Protokoll aller Arbeiten an Datensätzen im Backoffice. Dieses kurze Video ist ein geführter Rundgang durch das Protokoll.

## Was das Video zeigt

1. Jede Zeile ist eine Aktivität an einem Datensatz, etwa einem Kunden, einem Los, einer Rechnung oder einer Abrechnung.
2. Filtern Sie nach der ID, wenn Sie bereits wissen, welchen Datensatz Sie untersuchen.
3. Die Spalten Art und Info zeigen, was passiert ist und warum es protokolliert wurde.
4. Die Spalte Bearbeiter zeigt, wer die Änderung vorgenommen hat.
