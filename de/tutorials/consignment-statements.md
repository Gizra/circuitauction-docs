# Einlieferungsabrechnungen

Mit Einlieferungsabrechnungen rechnet das Auktionshaus mit jedem Einlieferer ab. Dieses kurze Video ist ein geführter Rundgang durch die Abrechnungsliste und eine einzelne Abrechnung.

## Was das Video zeigt

1. Öffnen Sie **Einlieferungsabrechnungen** im Hauptmenü.
2. Filtern Sie danach, wie viel der Abrechnung bezahlt wurde: nichts, eine Teilzahlung oder der volle Betrag.
3. Öffnen Sie eine Abrechnung. Der Status zeigt, an welcher Stelle des Abrechnungsablaufs die Abrechnung steht.
4. Die Lostabelle listet jedes verkaufte Los, das über diese Abrechnung ausgezahlt wird.
