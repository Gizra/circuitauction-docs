# Einlieferungen

Eine Einlieferung ist die Vereinbarung, mit der ein Einlieferer Lose an das Auktionshaus gibt. Dieses kurze Video ist ein geführter Rundgang durch die Einlieferungsliste und eine Einlieferung.

## Was das Video zeigt

1. Öffnen Sie **Einlieferungen** im Hauptmenü.
2. Sie können die Einlieferungen danach filtern, ob beim Eigentümer eine E-Mail-Adresse hinterlegt ist.
3. Öffnen Sie eine Einlieferung. Die Einlieferungs-ID kennzeichnet die Vereinbarung mit dem Einlieferer.
4. Das Feld Einlieferer verweist auf den Kunden, der die Lose eingeliefert hat.
