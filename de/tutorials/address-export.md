# Adressexport

Über den Adressexport erstellt das Auktionshaus Versandlisten genehmigter Kunden. Dieses kurze Video ist ein geführter Rundgang durch den Adressexport.

## Was das Video zeigt

1. Nur genehmigte Kunden werden exportiert. Der blaue Hinweis sorgt dafür, dass niemand an eine ungeprüfte Adresse verschickt.
2. Mit **Aus früherem Export duplizieren** können Sie von einer früheren Liste ausgehen. Die Schaltfläche bleibt inaktiv, bis Sie einen Export auswählen.
3. Unter **Create New Export** legen Sie Adresstyp, Titel und optionale Kundenfilter fest.
4. **Export History** listet jede Liste, die bereits erstellt wurde. Öffnen Sie eine, um ihre Adressen zu prüfen.
