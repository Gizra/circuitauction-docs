# Kategorien

Kategorien sind die Loskategorien des öffentlichen Katalogs. Dieses kurze Video ist ein geführter Rundgang durch den Kategorienbaum und seine Übersetzungen.

## Was das Video zeigt

1. Öffnen Sie **Kategorien** unter **Mehr** im Hauptmenü.
2. Der Baum ist die aktuelle Kategoriestruktur. Ziehen Sie eine Zeile, um sie unter eine andere Kategorie zu verschieben.
3. Geben Sie einen Namen in das Feld ein, um eine Kategorie hinzuzufügen. Gespeichert wird erst, wenn Sie auf **Speichern** klicken.
4. Unter **Kategorien Übersetzung** bearbeiten Sie die Kategorienamen in allen aktivierten Sprachen.
5. Jede Spalte ist eine Sprache. Klicken Sie auf eine Zelle, um die Bezeichnung zu bearbeiten, oder drücken Sie Escape, um abzubrechen.
6. Die Schaltfläche **Kategorien** bringt Sie zurück zum Baum.
