# Meine Interessen

**Selektor:** `#my-interests` &nbsp;•&nbsp; *einmal pro Seite* &nbsp;•&nbsp; **Anmeldung erforderlich**

## Funktion

Ermöglicht es dem Bieter, die Auktionskategorien zu verwalten, die ihn interessieren, damit das System Benachrichtigungen und Empfehlungen darauf abstimmen kann:

- **Add categories** — Autocomplete-Suche, um neue Kategorien zu finden und hinzuzufügen.
- **My categories** — eine Tabelle mit automatisch erkannten und manuell hinzugefügten Kategorien, mit Hierarchiesuche, Filter aktiv/inaktiv, sortierbaren Spalten (Name, Hierarchie, Gebote, gewonnen, Favoriten) und einem Ein/Aus-Schalter pro Kategorie. Auf kleinen Bildschirmen wird sie zu Karten umgebrochen.
- **Additional interests** — ein Freitextfeld für Interessen, die keiner Kategorie zugeordnet sind.

## So fügen Sie es hinzu

```html
<div id="my-interests" class="circuit-user-ui"></div>
```
