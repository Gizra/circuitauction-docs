# Magazin-Abonnement

**Selektor:** `#subscription-magazine` &nbsp;•&nbsp; *einmal pro Seite*

## Funktion

Zeigt eine Bibliothek von Magazin-Flipbooks als Raster von Titelbildern. Der Zugriff hängt vom Abonnement des Bieters ab:

- **Nicht angemeldet** — ein Anmeldehinweis.
- **Kein / abgelaufenes Abonnement** — eine Statusmeldung mit einem Link zum Erwerben oder Verlängern.
- **Aktives Abonnement** — die Flipbooks lassen sich zum Lesen öffnen.

## So fügen Sie es hinzu

```html
<div id="subscription-magazine" class="circuit-user-ui"></div>
```

## Optionen

Keine.
