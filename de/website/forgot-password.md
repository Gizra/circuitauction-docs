# Passwort vergessen

**Selektor:** `#forgotpassword` &nbsp;•&nbsp; *einmal pro Seite*

## Funktion

Ein Formular zum Anfordern des Zurücksetzens des Passworts. Der Bieter gibt seine E-Mail-Adresse ein, besteht die reCAPTCHA-Prüfung, und es wird eine E-Mail zum Zurücksetzen gesendet. Eine Erfolgs- oder Fehlermeldung wird direkt an Ort und Stelle angezeigt.

## So fügen Sie es hinzu

```html
<div id="forgotpassword" class="circuit-user-ui"></div>
```

## Optionen

Keine.
