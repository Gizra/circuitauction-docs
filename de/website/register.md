# Registrierung

**Selektor:** `#register` &nbsp;•&nbsp; *einmal pro Seite*

## Funktion

Ein Registrierungsformular für neue Konten: E-Mail, Passwort (mit Bestätigung), Name und Telefon sowie eine reCAPTCHA-Prüfung. Ist Ihre Website mit Partner-Backoffices verknüpft, wird ein optionales Kontrollkästchen zur Einwilligung in die Datenweitergabe an diese angezeigt. Bei Erfolg ist der Bieter registriert und die Ansicht [Mein Konto](website/my-account.md) wird angezeigt. Ist der Besucher bereits angemeldet, zeigt der Block statt des Formulars Mein Konto an.

## So fügen Sie es hinzu

```html
<div id="register" class="circuit-user-ui"></div>
```

## Optionen

Keine.
