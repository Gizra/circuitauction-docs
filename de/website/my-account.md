# Mein Konto

**Selektor:** `#my-account` &nbsp;•&nbsp; *einmal pro Seite* &nbsp;•&nbsp; **Anmeldung erforderlich**

## Funktion

Die Seite zur Kontoverwaltung des Bieters, aufgeteilt in drei Reiter:

- **Personal Info** — Name, E-Mail, Telefon, Adresse und Einstellungen.
- **Change Password** — ein neues Passwort festlegen.
- **Addresses** — mehrere gespeicherte Adressen hinzufügen, bearbeiten, löschen und eine davon als Standard festlegen.

Unterstützt Ihre Website mehr als eine Sprache, wird zusätzlich eine Sprachauswahl angeboten. Der Block setzt voraus, dass der Besucher angemeldet ist; andernfalls wird der Anmeldevorgang angezeigt.

## So fügen Sie es hinzu

```html
<div id="my-account" class="circuit-user-ui"></div>
```
