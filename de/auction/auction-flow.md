# Ablauf der Live-Auktion

## Losstatus während der Live-Auktion

**Stand by** - Das Bieten ist in Wartestellung.

**Open** - Das Bieten ist geöffnet. Bieter können auf das aktuelle Los bieten.

**Going** - Das Bieten wird gleich geschlossen. Bieter können weiterhin auf das aktuelle Los bieten.

**Gone** - Das Los ist für Gebote geschlossen und entweder verkauft oder unverkauft. Anschließend wird automatisch das nächste Los angezeigt.

Der Clerk ändert den Losstatus manuell auf dem Clerk Screen; der Status wird automatisch auf allen anderen Bildschirmen \(Auctioneer, Room und Web\) angepasst.
