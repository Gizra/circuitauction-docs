# Auktionssession festlegen

## Auktions-Session festlegen

1. Klicken Sie auf das Feld **Session** und wählen Sie die Session aus.

![](../../../assets/screenshots/clerk-session-select.png)

1. Klicken Sie nach der Auswahl auf den **Pfeil**, um die Session zu setzen. Beachten Sie: Wenn Sie nicht auf den Pfeil klicken, wird die ausgewählte Session nicht übernommen.
