# So fügen Sie einer Einlieferung ein Los hinzu

1. Stellen Sie sicher, dass Sie sich im richtigen [Auktionskontext](/de/sale/sale-context.md) befinden.
2. Öffnen Sie die Einlieferungsseite \(siehe [So finden Sie eine vorhandene Einlieferung](/de/consignment/how-to-find-an-existing-consignment.md)\).
3. Klicken Sie auf `Los einer Einlieferung hinzufügen`

![](../../assets/screenshots/consignment-add-item.png)

1. Fahren Sie mit Abschnitt 4 in [So legen Sie ein Los an](/de/items/how-to-create-an-item.md) fort.
