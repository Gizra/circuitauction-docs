# Release Notes

Dieser Bereich listet auf, was sich in der jeweiligen Version des CircuitAuction-Backoffice geändert hat. Jede Release-Seite gruppiert die neuen Funktionen und Verbesserungen nach Bereichen des Systems, sodass Sie schnell sehen, was für Ihre tägliche Arbeit relevant ist.

## Versionen

- **[Version 3.5](/de/release-notes/version-3.5.md)** (kommend) - Auction Timeline, Kundenstatistik, Kunden-CRM, Editor für E-Mail-Vorlagen, automatische Zahlungserinnerungen, Zwei-Faktor-Authentifizierung, dunkler Modus, HiBid-Import und mehr.
- **[Version 3.4](/de/release-notes/version-3.4.md)** (März 2026) - Schnellere Live-Bietengine, Quick Add Item, PDF- und Video-Dateien, Sammlertypen, Buy It Now, Mindestgebote, Besichtigungsmodul, Saldoverlauf, Zahlungen über Authorize.net.
- **[Version 3.3](/de/release-notes/version-3.3.md)** (Mai 2026) - Neugestaltung der Live-Auktionsbildschirme mit hellem und dunklem Modus, tastaturgesteuerter Clerk-Bildschirm, ShipStation und überarbeiteter Versand, WebP/AVIF-Vorschaubilder.
- **[Version 3.1](/de/release-notes/version-3.1.md)** (Juli 2025) - Inhaltstypen, Los-Stammbaum, KI-Assistent, verbundene Backoffices, WordPress-Magazinabonnements.

## So lesen Sie eine Release-Seite

- Die Funktionen sind nach dem Teil des Backoffice gruppiert, zu dem sie gehören (Auswertungen, Rechnungen, Aufgaben, Auktionen, ...).
- Wo eine passende Hilfeseite existiert, verlinkt die Release Note darauf.
- Einstellungen, die konfiguriert werden müssen (standortweite Standardwerte, Optionen pro Auktion), werden in der Beschreibung der Funktion erwähnt.
