# Export accounting

Export accounting is how invoices and consignment statements leave the backoffice for the finance system. This short video is a guided tour of it.

## What the video covers

1. The tabs switch between **Invoices** and **Consignment statements**. Some houses also see an **Avalara** tab for tax.
2. Filter the invoice list by order number, by type, or by whether it has already been exported.
3. The invoices table appears below the filters once the sale data loads. Column filters sit in the table footer.
4. **Dry run** previews the export without sending anything. Leave it on while you learn the screen.
5. The **Export** button sends the filtered invoices.
6. The **Consignment statements** tab exports seller settlements the same way, with the same **Dry run** option and **Export date**.

See also [How Consignment Statements are Created](consignment/how-consignment-statement-are-created.md).
