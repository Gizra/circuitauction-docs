# Address export

Address export is how the auction house builds mailing lists of approved clients. This short video is a guided tour of it.

## What the video covers

1. Only approved clients are exported. The blue notice is there so that nobody mails an unverified address.
2. **Duplicate from a previous export** lets you start from an earlier list. The button stays disabled until you choose an export.
3. **Create New Export** sets the address type, a title and optional client filters.
4. **Export History** lists every list that has already been built. Open one to review its addresses.

See also [How to Approve a Client](client/how-to-approve-a-client.md).
