# Understanding the Client Page

On top of the page you will find several tabs described below.

![](../assets/screenshots/client-page-tabs.png)

## Client

Information about the client, divided into sections: basic details like name and contact details, financial information, auction information \(for example if there is a warning related to this client\), shipping preferences and website access.

At the bottom of the Client tab you can find a list of the content revisions and the name of the user that changed it.

## Addresses

The client's addresses \(default, billing, shipping\).

## Bidding info

Under this tab you can choose several actions:

* Register [Bidder Number\(s\)](how-to-create-bidder-number.md) for this client.
* View a list of the [client's bids](how-to-view-clients-bids.md) on the [current sale](../sale/sale-context.md).
* [Place a new bid](how-to-place-a-bid-for-a-client.md) for this client.
* Approve the client's Bidding Limit requests and add Call requests.

## History

The client's bidding history across past sales.

## Viewings

Viewing appointments for this client.

## Consignments

List of the client's [consignments](../consignment/). This is only relevant for clients that are consignors.

## Items consigned

List of the items the client has consigned. This is only relevant for clients that are consignors.

## Items bought

List of the items the client has bought. This is only relevant for clients that are bidders.

## Bidder invoices

List of the client's bidder invoices.

## Transactions

The client's financial transactions.

## Statement of Account

A summary of the client's account balance.

## Activities

The activity log for this client.

## Emails and Documents

Here you can create documents from templates, send emails \(for example a [Bids Statement](how-to-send-a-bidding-report-to-a-client.md)\) and see everything that was sent to the client.

## Tasks

[Tasks](../tasks.md) related to this client.
