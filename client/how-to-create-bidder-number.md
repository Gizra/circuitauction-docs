# How to Create a Bidder Number

## Registering Bidder Numbers

1. Make sure you are on the right [sale context](../sale/sale-context.md).
2. Go to the Client Page \(see [How to Find an Existing Client](how-to-find-an-existing-client.md)\)
3. Go to the `Bidding info` tab.
4. Go to the `Bidder Numbers` section \(`Register New Bidder Numbers`\).
5. Select the bidder type \(Floor, Floor by agent, Website, Online, Phone or External\).
6. Enter the bidder number or leave it empty to let the system select the number. You can also enter an optional alias.
7. Click on **Register Bidder**.

![](../assets/screenshots/bidder-numbers-create.png)

1. Each bidder number will be in a separate block:

![](../assets/screenshots/bidder-numbers-blocks.png)

1. To limit how much the bidder can win, choose `Regular` on the **Bidding Limit** field, enter the amount and click on the save \(✓\) button.

![](../assets/screenshots/bidder-live-credit.png)

1. To limit how much the bidder can bid, choose `Regular` on the **Personal Limit** field, enter the amount and click on the save \(✓\) button. Note that the bidder may also change their personal limit through their My Account page.

![](../assets/screenshots/bidder-max-bid.png)

Note that you can register multiple Floor bidder numbers, but only one bidder number for Website or Phone.

## Creating Call Requests

1. Go to the `Add New Call Request` section.
2. Enter the **Lots** range. Use a comma \(,\) to separate lot numbers, and a dash \(-\) for ranges \(e.g. 101,200,300-310\).

![](../assets/screenshots/call-requests.png)

1. Enter a note if needed and click **Add Request**.
2. A phone bidder number will be created and added to the [Phone Bidder Cards list](how-to-download-phone-bidder-cards-list.md).

![](../assets/screenshots/call-requests-saved.png)
